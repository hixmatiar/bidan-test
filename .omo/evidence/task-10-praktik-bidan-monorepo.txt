=== 4) DEVIATION FROM SPEC: INSTEAD OF -> AFTER (documented in the file) ===
First attempt used exactly `INSTEAD OF UPDATE, DELETE`. SQL Server 2025 refuses it:

  Msg 2113, Level 16, State 1, Server sql-server-zyy, Procedure trg_audit_logs_immutable, Line 7
  Cannot create INSTEAD OF DELETE or INSTEAD OF UPDATE TRIGGER 'trg_audit_logs_immutable'
  on table 'dbo.audit_logs'. This is because the table has a FOREIGN KEY with cascading
  DELETE or UPDATE.

The cause is FK_audit_logs_users (users FK ON DELETE SET NULL, verified in section 2).
The trigger is therefore AFTER UPDATE, DELETE with RAISERROR(...) + ROLLBACK TRANSACTION,
which yields the same guarantee: no audit row can be changed or removed (QA 3 and QA 4).
Changing the FK to enable INSTEAD OF syntax would touch 01_schema.sql and is out of scope.
